D1·8gyv — 2026-08-01
chose: Derive a session's home initiative from the event logs themselves — scan for the session's earliest session_started, checking the branch-bound initiative first and only falling through to siblings on a miss
over: A new .sofar/sessions.json index mapping session_id to slug, written at registration and read by hooks
because: The home is ALREADY in the truth log — session_started names it uniquely — so an index file would be duplicated state that can desync, needs pruning (99 sessions and counting), and forces a SPEC Record-layout change plus a gitignore decision (routing is a local runtime fact, but .sofar/ is committed wholesale). It is also self-healing: sessions registered before this fix get pinned correctly with no migration. Same philosophy as reading git state rather than logging it — a fact with an authoritative home is read, never copied.
