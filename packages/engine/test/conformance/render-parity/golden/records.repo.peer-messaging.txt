D1 — 2026-08-08
rule: Peer resolution is an optional last inch: sofar must never bind an inbox socket or send a message itself, and no surface may become correct only when a peer resolves — the record-side line has to stand alone.
chose: sofar resolves the ADDRESS, Claude's own SendMessage delivers: read the host's undocumented ~/.claude/sessions/&lt;pid&gt;.json registry to map a Claude Code session id to the name SendMessage addresses, and annotate the two collision surfaces that already name that id (2.1's UserPromptSubmit line, 1.2's parallel_writebacks).
over: sofar posting directly into CLAUDE_CODE_MESSAGING_SOCKET (the first sketch), and building on Claude Code channels — the surface the messaging docs actually route external-event push to
because: Posting ourselves buys an undocumented wire format, an own-child verification rule that macOS can only satisfy while the poster is still running, inbound controls that HOLD non-child posts for user approval in any bypassPermissions session, and a delivered message billed to the user like a typed prompt. Worse, the exemption and the value are in tension: the socket's unique benefit is waking an IDLE session, and an idle session runs no hooks, so nothing of ours is alive to be its child. Channels are the doc-sanctioned path for external push but are closed to us — research preview, Anthropic auth, Bun, a restart with --channels, and only Anthropic-allowlisted plugins may register. Addressing has none of these failure modes: the agent doing the sending is already inside the host that owns the channel, so it sends under its own permissions, on its own turn, with its own tool. The mapping was the one open question and it is now verified live (2026-08-08, claude 2.1.226): the registry's sessionId is byte-identical to the session id sofar already stores from the hook JSON, and `name` is the address. Degradation is structural rather than disciplined — no registry, no address, and every surface renders exactly what it rendered before, which is asserted byte-for-byte in the tests. felt-cost D3 holds untouched: we hand over a string and call nothing.
