D1 — 2026-08-06
chose: Enforce the slug shape in TWO layers: @sofar/schema rejects a non-[a-z0-9-]+ `initiative` at the MCP tool boundary, AND resolveInitiative asserts the RESOLVED path is still contained under .sofar/initiatives/<slug>.
over: Validating only at the schema boundary, which is where the argument arrives and looks like the obvious single home for it.
because: The tool boundary is not the only way a slug reaches the path join. bindings.json is a committed, team-shared file that maps branch to slug with no schema in front of it, and CLI --initiative flags pass straight through. A PoC confirmed both routes wrote events.jsonl and projections outside the record. The schema regex is the belt; the containment assert is the brace, and it is stated in terms of the resolved path so `..`, an absolute path, a symlinked slug dir and a unicode separator all fail identically. SLUG_RE now has one home in the schema package and cli/new.ts re-exports it, so the two layers cannot drift.

== shard decisions/D2.md (1242 bytes) ==
<!-- generated by sofar — do not hand-edit; truth lives in events.jsonl -->

D2 — 2026-08-06
chose: Guard `sofar serve` on the Host header (must be loopback + the listening port) and on Origin (absent = non-browser, else must be loopback), checked in the request handler before routing; plus the SDK's enableDnsRebindingProtection/allowedHosts on the MCP transport as a second lock.
over: Relying on the existing 127.0.0.1 bind alone; or setting the SDK's allowedOrigins as well; or putting a token on /mcp.
because: Binding to loopback keeps other machines out but not the browser on this machine: DNS rebinding makes an attacker's page same-origin with the daemon, which then reads the whole record from /state and drives every write tool on /mcp — unauthenticated by design because "localhost" was assumed to authenticate. A rebound request still carries the attacker's hostname in Host, so that check is what actually closes it. allowedOrigins is deliberately left unset on the transport: the SDK treats a MISSING Origin as failure, which would lock out curl and every non-browser MCP client — our own originAllowed draws that line correctly instead. A token would break the zero-config local UX for no gain once Host is checked.

== shard decisions/D3.md (1340 bytes) ==
<!-- generated by sofar — do not hand-edit; truth lives in events.jsonl -->

D3 — 2026-08-06
chose: Redact credential-shaped material from command_run `cmd` before the append, matching on the SHAPE of a secret-bearing argument (NAME=value where NAME contains TOKEN/SECRET/API_KEY/…, --flag values, Authorization headers, user:pw@host, known token prefixes) and keeping the surrounding structure.
over: Dropping command capture entirely; redacting at render time; or an allowlist of known vendor token formats.
because: The log is append-only (BD5), committed, and pushed once linked — a secret that lands there cannot be edited out, only rewritten out of history by everyone who ever cloned. Before the append is the only moment it can be stopped, so render-time redaction is far too late. Shape-matching over a vendor allowlist because an unknown provider's token is exactly the one no allowlist catches. Structure is preserved (`AWS_SECRET_ACCESS_KEY=[redacted] terraform apply`) so the record still explains what ran, which is what makes this cheaper than dropping capture. Over-redaction costs a `[redacted]` in prose; under-redaction costs a live credential in a shared permanent file — the bias is deliberate. The self-recording exemption scan still reads the RAW text, so redaction cannot change which commands are exempt.

D4 — 2026-08-06
chose: Require api_url and any server-supplied verification URL to be https, with plain http allowed only for loopback hosts — refusing outright rather than warning. One home for the rule in client/url.ts.
over: Warning and proceeding; allowing http anywhere as before; or requiring https unconditionally and dropping the localhost dev path.
because: .sofar/remote.json is committed, so "which URL" is not purely the local user's choice — a merged change flipping api_url to http:// would put every teammate's bearer token on the wire in clear, and a warning on a command that still succeeds is a warning nobody reads.
