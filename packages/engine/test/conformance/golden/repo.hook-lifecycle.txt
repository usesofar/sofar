TypeScript keeps: the MCP server, `sofar drive`, init/doctor/review, and cloud commands.

The contract comes first: docs/SPEC.md plus a black-box conformance suite over commands, hook stdin/stdout, env and record bytes. It runs against BOTH implementations.

After parity, new hot-path code is Rust-only, which stops the TypeScript port surface growing. Distribution: prebuilt per-platform binaries through npm optionalDependencies, with a TypeScript fallback.
over: 
- A big-bang rewrite now: it freezes waves 1–3, leaves round 2 unable to attribute gains, and means porting 27.6k engine lines and 34k test lines before anything is trustworthy.
- Staying TypeScript-only behind a measure-first gate: the run owner's point is that the port cost grows with every feature, and Codex CLI, Turborepo and Biome show the path is proven.
because: 
- Sofar runs on every tool call of every agent session. A native core gives near-zero hook start-up, fast folds over very large records (this repo's own is 9.7 MB), a single binary with no Node dependency for Codex/Cursor/OpenCode users, and headroom for many parallel agents.
- Measured 0.31 hooks are only ~0.75% of session time today, so the win is future scale and distribution rather than today's tokens. That is why it goes incrementally, and must pass the same benchmark gate as any other change.
- A conformance-first strangler port means neither implementation can drift from the SPEC.
