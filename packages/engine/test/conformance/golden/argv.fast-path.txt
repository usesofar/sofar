Usage: sofar event [options] [command]

append-side surface: hook subcommands read hook JSON from stdin (SPEC §Hooks);
`append` is the convention dialect for MCP-less tools

Options:
  -h, --help                   display help for command

Commands:
  append [options] [slug]      append one validated event and regenerate
                               projections — the convention-dialect surface for
                               tools without MCP (prints {ok, event_id} JSON)
  types [options] [type]       payload reference for `event append`: every event
                               type, its fields, a validating example, and who
                               writes it
  session-start [options]      SessionStart hook: register the session in the
                               log, print the status projection (≤10,000 chars)
                               as injected context
  pre-tool [options]           PreToolUse hook: rewrite an agent's whole-file
                               read of plan.md, decisions.md, memory.md or
                               events.jsonl into `sofar read` (memory-lead 4.3);
                               every other call passes untouched
  post-tool [options]          PostToolUse hook: append mechanical file_touched
                               (Edit|Write|MultiEdit|apply_patch) / command_run
                               (Bash) events, and surface every repo-wide
                               decision that guards or names what the call
                               edited, read or ran
  post-tool-failure [options]  PostToolUseFailure hook: append the same
                               mechanical event with ok:false (and exit when the
                               host gives one); the error text goes to the
                               private diagnostics store, never the record
  post-tool-batch [options]    PostToolBatch hook (Claude Code): the read-time
                               surfacing of a whole batch of parallel calls as
                               one block, told once per session context; its
                               PostToolUse calls then only capture
  drive-await [options]        PostToolUse hook (Claude Code, asyncRewake):
                               after a Bash call that started a detached run,
                               wait on it and wake this session with one line
                               when it stops or its driver is gone
  user-prompt [options]        UserPromptSubmit hook: nudge an in-flow
                               write-back (one additionalContext line) when
                               drift since the last session_ended ≥5 events
  stop [options]               Stop hook: exit 2 (blocking) when the registered
                               session has not written back via session_ended;
                               loop-guarded by stop_hook_active
  session-end [options]        SessionEnd hook: append a mechanical
                               session_closed marker (fallback only)
  help [command]               display help for command
